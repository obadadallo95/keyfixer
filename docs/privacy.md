# KeyFixer Privacy Policy

**Effective date:** August 1, 2026

**Developer:** Obada Dallo

## macOS application

KeyFixer for macOS processes keyboard-layout conversions entirely on the user's device.

- **Text data:** KeyFixer does not collect, log, store, transmit, or share text entered into the application or text produced by a conversion.
- **Clipboard:** KeyFixer writes corrected text to the clipboard only after the user explicitly presses the Copy button. It does not read or continuously monitor clipboard contents.
- **Analytics and tracking:** The macOS application contains no analytics, advertising, crash-reporting, profiling, or tracking SDKs.
- **Network access:** Text conversion does not require a network connection or external service.
- **Accounts:** The application does not require or create user accounts.
- **Retention and deletion:** Because the application does not collect or retain personal data, there is no server-side user data to access, export, or delete. Text held temporarily in the application is removed when the user clears it or closes the application.
- **Global shortcut:** KeyFixer registers the user-visible shortcut `⌥⌘K` to show or hide its window. It does not record other keystrokes.

## Web application

The KeyFixer website performs text conversion locally in the browser. The website may use deployment-level traffic analytics that do not receive the text entered into the converter. Website analytics are separate from the macOS application.

## Chrome Extension

The Chrome Extension processes text locally. It may save the user's selected keyboard platform and conversion mode in `chrome.storage.local`. These preferences remain on the user's device and are not shared by KeyFixer.

## Third parties

The macOS application does not send user data to third parties. It contains no third-party advertising or analytics services.

## Changes

Material changes to this policy will be published with a new effective date. Changes will not retroactively permit collection or use of data without any consent required by applicable law.

## Support and privacy requests

Contact the developer through the [official support page](https://obadadallo.web.app/contact/).

# سياسة خصوصية KeyFixer

**تاريخ السريان:** 1 أغسطس 2026

**المطور:** عبادة دللو

## تطبيق macOS

ينفذ KeyFixer عمليات تصحيح تخطيط لوحة المفاتيح محليًا بالكامل على جهاز المستخدم.

- **بيانات النص:** لا يجمع التطبيق النصوص المدخلة أو الناتجة، ولا يسجلها أو يخزنها أو يرسلها أو يشاركها.
- **الحافظة:** يكتب التطبيق النص المصحح إلى الحافظة فقط عندما يضغط المستخدم زر النسخ. ولا يقرأ محتوى الحافظة أو يراقبها باستمرار.
- **التحليلات والتتبع:** لا يحتوي تطبيق macOS على خدمات تحليل أو إعلانات أو تقارير أعطال أو أدوات تتبع.
- **الاتصال بالشبكة:** لا يحتاج تحويل النص إلى اتصال بالإنترنت أو خدمة خارجية.
- **الحسابات:** لا يتطلب التطبيق إنشاء حساب أو تسجيل الدخول.
- **الاحتفاظ والحذف:** لأن التطبيق لا يجمع بيانات شخصية أو يحتفظ بها، فلا توجد بيانات مستخدم مخزنة على خادم لعرضها أو تصديرها أو حذفها. يُزال النص المؤقت عند مسحه أو إغلاق التطبيق.
- **الاختصار العام:** يسجل KeyFixer الاختصار الظاهر للمستخدم `⌥⌘K` لإظهار النافذة أو إخفائها، ولا يسجل ضغطات المفاتيح الأخرى.

## تطبيق الويب

ينفذ موقع KeyFixer التحويل محليًا داخل المتصفح. قد يستخدم الموقع تحليلات عامة لحركة الزيارة لا تستقبل النص الذي يدخله المستخدم في أداة التحويل. تحليلات الموقع منفصلة عن تطبيق macOS.

## إضافة Chrome

تعالج الإضافة النص محليًا، وقد تحفظ اختيار تخطيط لوحة المفاتيح ووضع التحويل في `chrome.storage.local`. تبقى هذه التفضيلات على جهاز المستخدم ولا يشاركها KeyFixer.

## الأطراف الخارجية

لا يرسل تطبيق macOS بيانات المستخدم إلى أطراف خارجية، ولا يحتوي على خدمات إعلانات أو تحليلات خارجية.

## التغييرات

ستُنشر التغييرات الجوهرية على هذه السياسة مع تاريخ سريان جديد، ولن تسمح التغييرات بأثر رجعي بجمع البيانات أو استخدامها دون أي موافقة يفرضها القانون.

## الدعم وطلبات الخصوصية

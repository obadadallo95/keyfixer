# KeyFixer v1.2.0 Release Pack

This document contains the complete release specifications, store metadata, verification checklists, and rollback plans for **KeyFixer v1.2.0** on macOS and Windows.

---

## A. Release Summary

**KeyFixer v1.2.0** introduces the **One-Key Toggle Workflow** for desktop applications across macOS and Windows. This keyboard-first update allows users to invoke the application with a single global shortcut (`⌥⌘K` on macOS, `Ctrl+Alt+K` on Windows), which automatically reads clipboard text, pastes and converts it instantaneously, and on a second shortcut press copies the corrected result with a subtle visual confirmation and dismisses the window.

This release also adds deterministic native clipboard integration via `tauri-plugin-clipboard-manager`, an explicit frontend state machine (`Idle` → `ResultReady`), and an optional, non-blocking native system sound feedback toggle (`Pop` on paste/fix, `Tink` on accept/copy on macOS; `SystemSounds::Beep` on Windows).

> [!NOTE]
> **Free Release Boundary**: v1.2.0 is strictly a free update. It contains **no** Pro paywall, in-place inline text replacement, trial counters, In-App Purchases, or external payment links.

## D. Feature List

- **One-Key Toggle Workflow**:
  - First Press: Focuses window, reads clipboard natively, converts text layout instantly, transitions state to `ResultReady`.
  - Second Press: Copies converted text to clipboard, triggers visual glow feedback, hides window, resets state to `Idle`.
- **Global Shortcuts**:
  - macOS: `⌥⌘K` (`Option + Command + K`)
  - Windows: `Ctrl + Alt + K`
- **Native Clipboard Integration**:
  - Utilizes `@tauri-apps/plugin-clipboard-manager` for deterministic OS-level clipboard read/write without browser security or focus restrictions.
  - Strict privacy rule: Clipboard is read only upon explicit shortcut trigger and written only upon explicit acceptance. Never monitored in the background.
- **Visual Feedback**:
  - 350ms subtle amber glow highlight around the result container upon copying.
- **Optional Native Auditory Feedback (Opt-In)**:
  - Default: **OFF** for all fresh installations.
  - Compact icon toggle in the controls toolbar. Setting persisted in `localStorage`.
  - macOS: `Pop.aiff` on paste/fix, `Tink.aiff` on copy/close.
  - Windows: Single native system confirmation sound (`SystemSounds::Beep`).
  - Executed on a background thread in Rust; never blocks UI, clipboard operations, or window dismissal.
- **State-Machine Robustness**:
  - Deterministic state transitions (`Idle` ↔ `ResultReady`).
  - Safe concurrent rapid-press handling (locks processing flag).
  - Preserves user input across window blurs; text is only cleared upon completed copy workflow or manual trash button click.
  - Manual tray/dock open auto-selects existing text for quick typing without triggering accidental copies.

## F. Release Checklist

### macOS (Mac App Store)
1. Ensure working directory is on `feat/one-key-workflow` and clean.
2. Run version verification:
   ```bash
   npm run version:check
   ```
3. Run complete pre-release validation suite:
   ```bash
   npm run release:check
   ```
4. Build and verify the App Store bundle:
   ```bash
   npm run build:appstore
   npm run verify:appstore
   ```
5. Package the signed installer with `productbuild`:
   ```bash
   productbuild --component src-tauri/target/release/bundle/macos/KeyFixer.app /Applications --sign "3rd Party Mac Developer Installer: Obada Dallo (D84FNM2R2N)" ~/Desktop/KeyFixer-1.2.0-AppStore.pkg
   ```
6. Verify package signature:
   ```bash
   pkgutil --check-signature ~/Desktop/KeyFixer-1.2.0-AppStore.pkg
   ```
7. Open Apple **Transporter** application, add `~/Desktop/KeyFixer-1.2.0-AppStore.pkg`, and upload.
8. Navigate to **App Store Connect** → KeyFixer → Prepare for Submission (1.2.0).
9. Select the uploaded build, paste the What's New release notes (English & Arabic), and submit for review.

### Windows (Microsoft Store)
1. Ensure working directory is on `feat/one-key-workflow` and clean.
2. Run version verification:
   ```bash
   npm run version:check
   ```
3. Run release checks:
   ```bash
   npm run release:check
   ```
4. Build the Windows binaries and MSIX package:
   ```bash
   npm run build:desktop
   npm run build:windows
   npm run build:windows:msix
   ```
5. Verify output artifacts in `src-tauri/target/release/bundle/`:
   - MSIX: `src-tauri/target/release/bundle/msix/KeyFixer_1.2.0.0_x64.msix`
   - NSIS: `src-tauri/target/release/bundle/nsis/KeyFixer_1.2.0_x64-setup.exe`
6. Log in to **Microsoft Partner Center** → KeyFixer → Submissions.
7. Upload `KeyFixer_1.2.0.0_x64.msix` under Packages.
8. Paste the What's New release notes (English & Arabic).
9. Submit to the certification queue.

## G. Rollback & Contingency Notes

- **If Apple Rejects v1.2.0**:
  - Address review feedback on `feat/one-key-workflow` or a targeted `fix/` branch.
  - v1.1.2 remains unaffected in the store (or in queue).
  - Do not bump minor version until rejection items are resolved.
- **If Microsoft Package Validation Fails**:
  - Inspect `AppxManifest.xml` and make sure `Identity Name="ObadaDallo.KeyFixer"` and `Publisher="CN=A2B67C57-E9AA-4233-B229-7A21800FE184"` match Partner Center exactly.
  - Ensure `runFullTrust` is the only restricted capability.
- **If Local Build Fails**:
  - Clean build directories via `npm run clean && npm run build:appstore:clean`.
  - Re-run `npm ci && npm run version:check && cargo clean` inside `src-tauri`.
